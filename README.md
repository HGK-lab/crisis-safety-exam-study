# 위기대응과 안전관리 시험 대비

교안 2~6장(44쪽 가연물의 구비조건까지)을 폰으로 정리하고 연습하는 정적 사이트.

- **흐름 정리**: 장별 핵심 정리. 헷갈리는 짝은 좌우 비교, 교안 빈칸은 확인된 것만 눌러서 답 보기
- **목록 훈련**: 번호 목록 41개. 떠올리기 / 아닌 것 고르기(시험 형식)
- **실전 문제**: 직접 쓴 41문항. 짝 구분, 누구의 정의, 사례 적용, 교안 빈칸, 서술형(키워드 채점)

정답은 교안 문구 기준이다. 수업 녹음으로만 확인된 빈칸은 "수업 설명"으로 따로 표시하고, 답을 확인하지 못한 빈칸은 비워 둔다.

## 구조

빌드 도구 없음. `data/*.js`가 `window.*`에 데이터를 넣고, `logic.js`(보기 섞기)와 `app.js`(화면)가 쓴다.

```
node --test tests/*.test.mjs   # 로직 + 데이터 검수
```
